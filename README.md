# Chicagoland Podcast Studio

Next.js App Router site converted from the Bootstrap HTML prototype.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Source |
| --- | --- |
| `/` | Home |
| `/studio` | The Studio |
| `/services` | Services |
| `/how-it-works` | How It Works |
| `/pricing` | Pricing (package tabs) |
| `/booking` | Booking enquiry form |

## Stack

- Next.js 16 (App Router)
- React 19
- Bootstrap 5
- GSAP + ScrollTrigger
- Original site CSS in `app/styles/`

## Scripts

```bash
npm run dev      # development server
npm run build    # production build
npm run start    # serve production build
```
